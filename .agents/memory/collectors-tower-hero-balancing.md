---
name: Collector's Tower Hero balancing
description: Why Hero base stats and promotion boost magnitudes stay placeholder, and how they should eventually be tuned.
---

Hero base stats (attack/HP) and promotion-tier boost magnitudes are placeholder by design — unlike Soldiers, there is no real reference spreadsheet/table for Heroes, so there is no "correct" number to look up or research.

**Why:** The user explicitly said not to guess at balancing numbers for systems with no source data. Soldiers had a real progression spreadsheet to draw from; Heroes never did.

**How to apply:** Don't propose or build a "replace Hero placeholders with real data" task by researching/inventing numbers. The only valid path is playtesting the current placeholder values in the running game and tuning by feel once there are opinions about what feels too weak/strong. Revisit only when the user brings feedback from actual play sessions.
